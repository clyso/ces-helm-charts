CES Helm charts

Helm charts for Clyso Enterprise Storage (CES) on Kubernetes, through Rook. Each chart wraps an upstream Rook or ceph-csi chart at an exact version, and carries it in its package.

Add the repository

helm repo add clyso <the address of this page>
helm repo update clyso
helm search repo clyso

Install CES

Install the three charts in this order, all at the same version. Rook's pods run privileged: where Pod Security admission is enforced, label the namespace pod-security.kubernetes.io/enforce=privileged first.

helm install ces-rook-operator clyso/ces-rook-operator --version @@CES_VERSION@@ -n rook-ceph --create-namespace --wait
helm install ces-csi-drivers clyso/ces-csi-drivers --version @@CES_VERSION@@ -n rook-ceph --wait
helm install ces-ceph-cluster clyso/ces-ceph-cluster --version @@CES_VERSION@@ -n rook-ceph -f cluster.yaml

cluster.yaml names the CES release the cluster runs, in rook-ceph-cluster.cephImage.tag (such as ces-v19.2.6-1), and the cluster's own layout: its nodes and devices, pools and filesystems. ces-csi-drivers is needed only when pods in the Kubernetes cluster use Ceph volumes.

Without helm repo add, name the repository with --repo and the chart by its bare name:

helm install ces-rook-operator ces-rook-operator --repo <the address of this page> --version @@CES_VERSION@@ -n rook-ceph --create-namespace --wait
